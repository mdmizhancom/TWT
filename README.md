# Tiles Works Tracer (টাইলস কাজ ও মজুরি ট্র্যাকার)

টাইলস মিস্ত্রি, হেল্পার ও নির্মাণ কাজের দৈনিক হাজিরা, মজুরি, অগ্রিম টাকা এবং সাইট খরচের খতিয়ান রাখার একটি আধুনিক, সম্পূর্ণ রেসপনসিভ ও নিরাপদ ওয়েব অ্যাপ্লিকেশন।

---

## 🚀 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

1. **দৈনিক হাজিরা ও মজুরি খাতা (Daily Attendance & Wage Tracker):**
   - কোন কারিগর কোন বিল্ডিংয়ে কাজ করেছে, তার দৈনিক মজুরি কত এবং কত টাকা অগ্রিম নিয়েছে তা সহজেই লিখে রাখা যায়।
   - টাইলসের কাজের পরিমাণ (SqFt) ও কাজের বিস্তারিত বিবরণ লেখার সুবিধা।

2. **বিল্ডিং ও প্রজেক্ট ওয়াইজ হিসাব (Site & Project Management):**
   - একাধিক বিল্ডিং/সাইটের কাজ আলাদাভাবে পরিচালনা।
   - কোন বিল্ডিংয়ে মোট কত টাকা খরচ হলো, কত মজুরি দেওয়া হয়েছে এবং মালামাল বাবদ কত খরচ হলো তা স্বয়ংক্রিয়ভাবে হিসাব করা হয়।

3. **কারিগর ও শ্রমিকদের ব্যক্তিগত খতিয়ান (Worker Directory & Ledger):**
   - মেস্তুরি, টাইলস কাটার, হেল্পার ও সাধারণ লেবারদের আলাদা তালিকা।
   - মোট কত টাকা আয় করলো, কত অগ্রিম নিলো এবং কত বকেয়া রয়েছে তার স্বচ্ছ হিসাব।

4. **স্মার্ট ফিল্টারিং ও সার্চ (Advanced Multi-Filter):**
   - নির্দিষ্ট বিল্ডিং অনুযায়ী ফিল্টার।
   - নির্দিষ্ট কারিগর বা মিস্ত্রি অনুযায়ী ফিল্টার।
   - পদবি/রোল বা নির্দিষ্ট তারিখের রেঞ্জ অনুযায়ী ফিল্টার।

5. **সিকিউরিটি ও অ্যাডমিন মোড লক (Admin PIN Protection):**
   - সাধারণ ভিউয়ার মোডে কেবল হিসাব দেখা যাবে (Viewer Mode)।
   - নতুন এন্ট্রি, ডাটা এডিট বা ডিলিট করতে ৪ সংখ্যার পিন কোড দিয়ে অ্যাডমিন মোড আনলক করতে হবে।
   - **ডিফল্ট অ্যাডমিন পিন (Default PIN):** `1234` (যা সেটিংস থেকে যেকোনো সময় পরিবর্তন করা যায়)।

6. **প্রিন্ট ও CSV এক্সপোর্ট (Print & Reports):**
   - যেকোনো তারিখ বা প্রজেক্টের ভাউচার/রিপোর্ট প্রিন্ট এবং এক্সেল/CSV ফাইল হিসেবে ডাউনলোড করার সুবিধা।

7. **ফায়ারবেস ক্লাউড ডাটাবেস (Firebase Firestore Integration):**
   - রিয়েল-টাইম ক্লাউড সিঙ্ক এবং লোকাল ব্যাকআপ ব্যবস্থা।

## 🌐 GitHub Pages-এ হোস্ট করার নিয়ম (How to Deploy to GitHub Pages)

1. গিটহাবে একটি নতুন রিপোজিটরি (Repository) তৈরি করুন (যেমন: `tiles-works-tracer`)।
2. আপনার প্রজেক্ট ফোল্ডারের টার্মিনালে নিচের কমান্ডগুলো চালান:

```bash
git init
git add .
git commit -m "Initial commit - Tiles Works Tracer"
git branch -M main
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/<REPO_NAME>.git
git push -u origin main
```

3. গিটহাব রিপোজিটরির **Settings** > **Pages** ট্যাবে যান।
4. **Source** হিসেবে `Deploy from a branch` নির্বাচন করে **Branch** `main` এবং ফোল্ডার `/ (root)` সিলেক্ট করে **Save** দিন।
5. কয়েক মিনিটের মধ্যেই আপনার সাইট লাইভ হয়ে যাবে!

## 🔒 Firebase Firestore Security Rules

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
```
